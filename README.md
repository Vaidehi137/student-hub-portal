🎓student hub portal🎓
## Project Description
StudentHub is a simple student portal website developed using HTML, CSS, and JavaScript. It allows students to access academic information such as courses, attendance, assignments, results, notices, and profile details.

## Features
- Student Login
- Dashboard
- Courses
- Attendance
- Assignments
- Results
- Notice Board
- Student Profile
- Contact Page

## Technologies Used
- HTML5

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
